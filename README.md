# TerraPure Organics - Organic Fertilizer & Manure Supplier Website

A modern, responsive, high-performance website designed and engineered for an **Organic Fertilizer & Natural Manure Supplier** business. The website embodies an earthy, natural, eco-friendly aesthetic with modern typography, fluid scroll animations, Light/Dark mode, RTL compatibility, and an intuitive user experience.

---

## 🌾 Project Overview

- **Business Name:** TerraPure Organics & Bio-Manure Private Limited
- **Domain Focus:** Certified Organic Fertilizers, Aged Cow Dung Manures, Vermicompost, Cold-Pressed Neem Cake, Poultry Manure, Bone Meal, and Bio-Potash.
- **Technology Stack:** HTML5, CSS3, JavaScript (ES6+), Bootstrap 5.3.3, Bootstrap Icons.
- **Design Paradigm:** Mobile-First Responsive, Earthy Eco-friendly Color Palette, Dark/Light Mode with localStorage persistence, Full RTL (Right-to-Left) Arabic/Hebrew compatibility.

## 🎨 Theme & Accessibility Features

1. **Light & Dark Mode:**
   - One-click toggle in the navbar and mobile menus.
   - Detects system preference (`prefers-color-scheme`) and persists choice in `localStorage`.
   - Dark mode uses deep organic slate tones (`#0d1611`, `#142219`) with bright emerald accents.

2. **Full RTL (Right-to-Left) Compatibility:**
   - Dedicated `RTL` toggle button on every page.
   - Sets `dir="rtl"` on `<html>` and applies `assets/css/rtl.css`.
   - Automatically mirrors button icons, badges, timelines, form alignments, and tables.

3. **Fluid Micro-Animations:**
   - Scroll reveal animations powered by lightweight `IntersectionObserver`.
   - Dynamic numerical counter animation for statistical metrics.
   - Image hover zooms, card elevations, and smooth transition effects.

## 🚀 How to Run the Website

Because this is a pure, static website using modern standards:
1. Simply double-click any `.html` file (e.g. `index.html`) in your browser (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari).
2. Or serve it via any local development server:
   - **VS Code Live Server:** Right-click `index.html` -> "Open with Live Server"
   - **Node.js:** `npx serve .`
   - **Python:** `python -m http.server 8080`

All images, styles, scripts, and fonts load smoothly without needing any compilation or build steps.
